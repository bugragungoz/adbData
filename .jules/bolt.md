## 2024-04-23 - O(1) Membership Check Performance Boost
**Learning:** In PowerShell, using `+=` to append to an array creates a full copy of the array every time, resulting in O(N^2) complexity. When tracking large numbers of completed or failed files, this is a significant bottleneck. Furthermore, PowerShell array lookup with `-notcontains` is O(N). `System.Collections.Generic.HashSet[string]` solves both problems, providing O(1) appends and lookups.
**Action:** When accumulating a large dataset in a tight loop where membership checking is also required, always initialize collections using `[System.Collections.Generic.HashSet[string]]::new([System.StringComparer]::OrdinalIgnoreCase)` and cast `.Add()` calls to `[void]` to avoid pipeline pollution. Remember to manually convert HashSets back to lists for JSON serialization using `[System.Collections.Generic.List[string]]::new($hashset)` as ConvertTo-Json in older PowerShell versions fails to properly unroll HashSets.
