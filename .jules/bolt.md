## 2025-05-24 - PowerShell Generic List Performance\n**Learning:** System.Collections.Generic.List[T] is significantly faster and more type-safe than System.Collections.ArrayList in PowerShell loops, and List[T].Add() doesn't pollute the pipeline with boolean/index returns (so [void] casts can be safely removed).\n**Action:** Use Generic.List[T] instead of ArrayList for all high-frequency iteration blocks in PowerShell scripts.
